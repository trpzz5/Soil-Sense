# SoilSense

## IoT-Based Smart Soil Monitoring and Crop Recommendation System

SoilSense is an IoT-based smart agriculture system designed to monitor soil conditions and help users identify suitable crops based on soil parameters.

The system uses an ESP32 microcontroller and soil sensors to collect soil-related data. The collected data can be displayed through an application and used to support smarter and more data-driven crop selection.

## Key Features

- Real-time soil monitoring
- Soil moisture measurement
- Soil pH monitoring
- NPK nutrient monitoring
- Soil data analysis
- Crop recommendation
- User-friendly application interface
- ESP32-based IoT system
- Wireless data communication
